# Отчёт по ДЗ №1: Task Manager

## 1. Доменная область

Менеджер задач (to-do list). Пользователь создаёт, просматривает,
редактирует и удаляет задачи, меняет статус (NEW / IN_PROGRESS / DONE).

## 2. Стек

| Слой | Технология |
|------|-----------|
| Язык | Java 25 (LTS) |
| Фреймворк | Spring Boot 4.1.1 |
| Web | Spring MVC + Tomcat 11 (встроенный) |
| Persistence | Spring Data JPA + Hibernate 7.4.5 |
| Валидация | Jakarta Bean Validation |
| Миграции | Flyway 12.4.0 (через `spring-boot-starter-flyway`) |
| СУБД | PostgreSQL 18.6 |
| Сборка | Maven 3.9.16 |
| Утилиты | Lombok 1.18.42 |
| Мониторинг | Spring Boot Actuator |
| Фронтенд | HTML + Vanilla JS + CSS |

## 3. Сущности

**Task** (`tasks`):
- `id` — BIGSERIAL, PK
- `title` — VARCHAR(255), NOT NULL
- `description` — VARCHAR(2000)
- `status` — VARCHAR(50), default `NEW`
- `createdAt`, `updatedAt` — TIMESTAMPTZ

DTO: `TaskRequest` (валидация `@NotBlank`), `TaskResponse`
(собирается через `from(Task)`). Слои: Controller → Service → Repository.

**API:**

| Метод | Путь | Код |
|-------|------|-----|
| GET | `/api/tasks` | 200 |
| GET | `/api/tasks/{id}` | 200/404 |
| POST | `/api/tasks` | 201/400 |
| PUT | `/api/tasks/{id}` | 200/404/400 |
| DELETE | `/api/tasks/{id}` | 204/404 |
| GET | `/actuator/health` | 200 |

## 4. Соответствие 12 факторам

| # | Фактор | Соответствие | Обоснование                                                            |
|---|--------|--------------|------------------------------------------------------------------------|
| 1 | Codebase | да           | Один Git-репозиторий, одна кодовая база                                |
| 2 | Dependencies | да           | Все зависимости в `pom.xml`, версии через Boot BOM                     |
| 3 | Config | да           | `${DB_URL}`, `${DB_USER}`, `${DB_PASSWORD}`, `${PORT}`                 |
| 4 | Backing services | да           | PostgreSQL как attached resource по URL из env                         |
| 5 | Build/release/run | частично     | Стадии разделены (jar + env), CI/CD нет — ограничение учебного проекта |
| 6 | Processes | да           | Stateless, состояние только в PostgreSQL                               |
| 7 | Port binding | да           | Встроенный Tomcat, `${PORT:8080}`                                      |
| 8 | Concurrency | непонятно    | реального масштабирования нет. Дальше будет видимо по требованиям      |
| 9 | Disposability | да           | Быстрый старт, `server.shutdown: graceful`                             |
| 10 | Dev/prod parity | да           | Одна СУБД, одни миграции, различия только в env                        |
| 11 | Logs | да           | stdout/stderr через Logback, файлов нет                                |
| 12 | Admin processes | да           | Миграции Flyway при старте, Actuator для мониторинга                   |

**Не реализовано (осознанно, вне рамок ДЗ):**
Docker, CI/CD, юнит-тесты, аутентификация.

## 5. Запуск

```sql
CREATE DATABASE taskdb;
CREATE USER taskuser WITH PASSWORD 'taskpass';
GRANT ALL PRIVILEGES ON DATABASE taskdb TO taskuser;
\c taskdb
GRANT ALL ON SCHEMA public TO taskuser;
```
```bash
mvn clean package
java -jar target/task-manager-1.0.0.jar
```

UI: http://localhost:8080 · API: http://localhost:8080/api/tasks
